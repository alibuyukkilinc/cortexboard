# Code of Conduct

Cortex follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good faith, and keep discussion about the work. Harassment,
personal attacks and discriminatory language are not accepted in issues, pull requests, discussions or any
other project space.

## Reporting

If someone's behaviour concerns you, contact the maintainers privately through GitHub (a private
vulnerability report on this repository reaches them without being public). Reports are kept confidential.
Maintainers may remove comments, close threads or block participants who do not follow this code.
